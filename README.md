# Bioinformatics Workshop 21-10-2026
Workshop Description: Bioinformatics & Next-Generation Sequencing Training
Date: 21 – 23 October 2026
Venue: Sugarbird, SAMRC Conference Centre
This workshop provides a comprehensive introduction to bioinformatics, with a focus on next-
generation sequencing (NGS), Linux, R programming, RNA-sequencing (RNA-seq) and Whole
genome sequencing (WGS) data analysis. Designed for students, the workshop combines theory
with practical sessions to equip participants with the essential skills needed for genomic data
analysis.
By the end of the workshop, participants will have gained:
A solid foundation in molecular biology, omics, and NGS technologies
Practical command-line skills for working with bioinformatics tools in Linux
Foundational R coding and data analysis skills
The ability to process, align, and quantify RNA-seq data
Experience identifying differentially expressed genes and visualising results
An understanding of WGS workflows, including variant calling and interpretation
An introduction to GitHub for collaborative and reproducible research
